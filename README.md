# 🌐 Rinaldi - Portfolio Website

This is my personal **portfolio website** built with **Next.js 15, React 19, and TypeScript**.  
The site showcases my projects, skills, professional experience, and contact information.

🚀 Live Demo: [View Portfolio](portofolio-seven-orpin.vercel.appp)

---

## ✨ Features

- 🎨 **Modern UI/UX** with Tailwind CSS and shadcn/ui components
- ⚡ Built with **Next.js 15 (App Router)** and **React 19**
- 📂 **Dynamic Projects Section** with live demo and GitHub code links
- 💼 **Professional Experience Timeline** with animations
- 🛠️ **Skills & Tech Stack Section**
- 📞 **Contact Form** with social media links
- 📱 Fully **responsive design** for desktop & mobile
- 🎥 Hover animations, transitions, and interactive previews

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/), [React 19](https://react.dev/)
- **Languages:** TypeScript, JavaScript (ES6+)
- **Styling:** Tailwind CSS, shadcn/ui
- **Icons & UI:** lucide-react
- **Data Visualization (for some projects):** Chart.js, Recharts, D3.js
- **Design Tools:** Figma
- **Deployment:** Vercel
